# Personal Website — Claude Context

## Project overview
A clean, minimal personal resume/portfolio site for Sabin Pradhan, a Data Scientist based in New Jersey. Built with plain HTML and CSS — no frameworks, no build step.

## Owner
- **Name:** Sabin Pradhan
- **Role:** Data Scientist
- **Location:** New Jersey

## Stack
- HTML5 + CSS3 only
- No JavaScript framework
- No bundler or build tool — open `index.html` directly in a browser

## Design philosophy
- Minimal and readable — content first
- Centered single-column layout, max 680px wide
- Georgia serif font for a polished editorial feel
- No external dependencies (no CDN fonts, no JS libraries)

## File structure
- `index.html` — main page (name, bio, sections)
- `styles.css` — all styling
- `README.md` — project documentation

## Conventions
- Keep all styles in `styles.css`, no inline styles
- Sections in `index.html` use `<section>` tags with an `<h2>` heading
- Class names are lowercase, hyphenated (e.g. `.bio`, `.container`)
